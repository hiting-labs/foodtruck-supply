# 행사 공급처 찾기

푸드트럭 행사장 근처의 얼음 · 가스 · 식자재 업체를 찾아 주는 웹 페이지입니다.

## 주요 기능

- 행사장 읍 · 면 · 동을 입력하거나 현재 위치로 주변 업체 검색 (카카오맵, 가까운 순)
- 반경 5km · 10km · 15km · 전체 선택, 지도로 보기
- 즐겨찾기, 전화 걸기, 주문 기록(수량 · 단가 · 메모)
- 지도에 없는 업체 직접 추가

## 구성

- `index.html` 한 파일 (빌드 없음)
- 카카오맵 JavaScript SDK 사용

## 배포

`main`에 머지되면 Vercel(프로젝트 `foodtruck-supply`)이 자동 배포합니다.
